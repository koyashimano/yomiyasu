# 論文・研究レポート（paper）

あわせて読む: domains/tech.md
lint で外す規則: なし

## 1. 普通な書き方（直さない）

論文、学会の予稿、卒業論文、研究レポート、調査報告。主張の確かさの度合い、引用、数値は、書き手が根拠に合わせて決めたもの。

- 慎重な表現（と考えられる、と思われる、可能性がある、示唆する、推測される、の範囲では、かもしれない）。「〜である」「〜を示す」の断定に変えない。逆に、断定を弱めることもしない。
- 引用の書き方（[1]、[2, 5]、(山田 2020)、(Smith et al., 2019)）、数値、単位、有意水準、統計の値（SD = 3.1、p < .05）。一字も変えない。引用の番号や括弧を別の文や句へ動かさない（どの主張を支える引用かが変わる）。
- 専門用語。読者を general と指定されても言い換えず、本文に説明も追加しない（audience.md 8章の言い換えより、この種類の規則を優先する）。
- 「である」調。「です・ます」に変えない。揃えるのは、地の文で2つが混ざっているときのみ。
- 「本研究では」「先行研究」と、「考察」「結論」などの見出し。domains/tech.md 3章の、過度な論文調を削る項目を適用しない。
- 条件と結果が1文にまとまっているほうが正確な長い文。文が長いことのみを理由に分けない（SKILL.md「段落と文の論理構造（つながり）」）。gemini-syntax.md 原則7 の平均の目安でも分けない。
- 名詞化の表現と正式な漢語（〜の実施、〜に関して、調査を行った）。slop-catalog.md 7章の名詞化の行のとおり残す。

## 2. それでも直すもの

- 誤字と脱字。同じ用語の表記の揺れを揃えるのは、他の種類と同じく表記の校正に任せる（SKILL.md「用途と表記の扱い」）。書き方の違いで別の概念と読めるおそれがあるときは、揃えずに「書き手に確かめたい点」で尋ねる。
- 係り先が分からない文と、主語と述語が噛み合わない文。長い文を分けるのはこのときのみで、係り先が1つに決まるときに限る。
- 「の」が4つ以上続く所。語順を変えるか、「の」の1つを内容に合う助詞や動詞にする。意味が1つに決まらなければ残す。
- 同じ文末が3文以上続く所。語順や文のまとめ方で整える。文末の種類を変えて散らさない（慎重な表現を断定にしない。「である」を「です」にしない）。
- 本文に残ったAIへの指示と、データや出典に基づかない誇張（slop-catalog.md 6章、7章）。読者のために扱う範囲や前提を示す文は残す。

## 3. 長さと省略

- 見出し、節、図表、引用文献の数と順序と番号を変えない。
- 数値と単位、統計の値、引用の書き方と、それが掛かる主張の範囲を変えない。
- 会話やファイルからは事実を補わない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| この結果は、AとBの間に関係がある可能性を示唆する。 | 残す（「関係がある」「関係を示す」にしない） |
| 平均は12.4（SD = 3.1, p < .05）であった [3]。 | 残す（数値、記号、引用の書き方を一字も変えない） |
| 本研究では、40名の参加者を対象に聞き取りの調査を行った。 | 残す（「本研究では」と「調査を行った」は論文の表現） |
| 今回の調査の範囲では、両群の間に差は見られなかった。 | 残す（「の範囲では」を消すと、調べていない所まで差がないと言うことになる） |
| 室温が25度を超え、かつ湿度が70%以上の条件でのみ、反応時間の増加が見られた。 | 残す（条件と結果を1文に保つ。分けると「のみ」が掛かる範囲がぼやける） |
| 本実験の結果の傾向の分析の手順は付録に示す。 | 修正する（本実験の結果の傾向を分析した手順は、付録に示す。） |
