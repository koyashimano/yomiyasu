# スライド（slides）

あわせて読む: domains/tech.md か domains/business.md（中身で選ぶ）
lint で外す規則: bare_verb_chain、bold_label_list、cleft_list_ending、count_declaration、excess_list、short_summary_heading

## 1. 普通な書き方（直さない）

- 短い句や体言止めの見出しと箇条書き、ラベルと値の項目。
- 目次と「ポイントは3つです」、まとめのページ。
- 箇条書きで強調として選んだ「〜のは、A、B、C」の形（lint の cleft_list_ending はこの種類では除外する）。
- `---` のページの区切り、Marp などのフロントマター、発表者ノート。
- スライドの前と後に付いた、依頼者あての前置きや注記（構成の説明、仮の値や仮の例の断り、誤記の補足、続けて作れるという申し出）。スライドの中身ではないので推敲せず、そのまま残す（slop-catalog.md 6章の「チャット応答の名残」として削らない）。必要がなければ書き手が削除する。中身から書き手に確かめたいことがあれば「書き手に確かめたい点」で尋ねる。

## 2. それでも直すもの

- 長い文の見出し。何を扱うページかが分かる短い項目名にする（SKILL.md「案内用の見出し」）。
- 縮めすぎた標語の見出し。補い方が1つに決まるときのみ補い、決まらなければ残して確認する。
- この2つと見出しの読点は、依頼で見出しの形（長さ、言い切り、番号、記号）や、まとめのページを指定されているときは修正せず、その形とページを保つ（SKILL.md「案内用の見出し」）。
- 「速い。軽い。安い。」の型（lint の fragment_run はこの種類でも除外しない）と絵文字。
- 見出しの読点。見出しには読点を残さない。
  - 並べた語は「・」でつなぐ。
  - 逆接、条件、理由や目的、時の句の後の読点と、主題の後に別の主語が続く所の読点も削除する（逆接や条件、理由を表す言葉は残す）。
  - 削除すると掛かり先が変わる見出しは語順を変え、削除しても長い見出しは上の「長い文の見出し」と同じく短くする。
  - 残すのはカギ括弧や引用符の中の読点と、数字の区切り（1,000）のみ。文書の題は変えない。
  - この種類のときのみ、lint の slide_comma が見出しの読点を、位置や前後の言葉に関係なく候補に出す。
- 1行の箇条書きの、間を作るのみの読点。箇条書きは一目で読むので、地の文なら残す読点でも、以下の読点は**削除する**。この種類のときのみ、lint の slide_comma が候補を出す。
  - 文頭の繋ぎの言葉の後（だから、そこで、結局）
  - 「振り返れば」「数字で言えば」のような決まった表現の後
  - 文頭の長い時や場面の句の後（その日のうちに、会議が終わるまでに）
  - 短い主題や主語の後（新しい手順では、大事なのは）
  - 目的語の「を」の後
- 1行の箇条書きでは、以下の読点は**残す**。
  - 逆接（のに、ても、けれども、ながらも、述語＋が）
  - 条件（なら、たら、「〜ときは」「〜場合は」、「上司に言えば」のような「〜ば」）
  - 理由や目的（ので、ために、ためには）
  - 名詞の並び
  - 「その夜、」「翌朝、」「始める前に、」のような短い時の句
  - 主題の後に別の主語が続く所（会議では、担当者が説明した。前の画面には、文字が小さいという声があった）
  - 長い行で「〜ではなく」の否定と言い直しを分ける所
  - 長い主語の後
  - 削除すると掛かり先が変わる所
  - カギ括弧や引用符の中

## 3. 長さと省略

- ページの数と順序、ページの中の項目の順序を変えない。説明の文をページに追加しない。
- 箇条書きの1項目は1行に収まる長さを保つ。体言止めと助詞の省略を残し、文にのばさない。
- 見出しの記号（#）がない文字（PowerPoint から転記したもの）には見出しの規則を適用しない。
- 新規作成では、スライドに番号を付ける。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| - キャッシュの期限を短縮 | 残す（体言止めの項目。「短縮しました。」にしない） |
| ## ポイントは3つです | 残す（目次のページ） |
| ## だから、引き継ぎの資料を先に作った | 読点を削除する（## だから引き継ぎの資料を先に作った） |
| ## 霧が出たら、ロープウェイを運休する | 読点を削除する（## 霧が出たらロープウェイを運休する）。見出しでは条件の読点も残さない |
| ## 下ごしらえ、煮込み、盛り付け | 「・」でつなぐ（## 下ごしらえ・煮込み・盛り付け） |
| ## 「晴れ、のち雪」の予報 | 残す（カギ括弧や引用符の中の読点） |
| ## 標高2,450メートルの山小屋 | 残す（数字の区切り） |
| - その日のうちに、手順書を書き直した | 読点を削除する（- その日のうちに手順書を書き直した） |
| - 急ぎなら、電話で連絡する | 残す（1行の箇条書きの条件の読点） |
| - その夜、直す前と後を比べた | 残す（短い時の句の読点） |
| - 前の画面には、文字が小さいという声があった | 残す（主題の後に別の主語が続く読点） |
| ## 速さは、信頼。 | 修正する候補。何を扱うページかが分かる見出しに戻す。補い方が1つに決まらなければ修正せずに確認する。依頼で見出しの形を指定されていれば修正しない |
