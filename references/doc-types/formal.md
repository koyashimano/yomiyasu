# 公用文、規程、契約書、仕様書（formal）

あわせて読む: domains/business.md か domains/tech.md（中身で選ぶ）
lint で外す規則: なし

## 1. 普通な書き方（直さない）

- 正式な漢語と定義された言葉（実施する、行う、届出、甲、乙）。和語に言い換えない。
- 義務の言葉（しなければならない）、権限の言葉（することができる）、許可の言葉（してよい、差し支えない）、努力の言葉（努めるものとする）と、「〜するものとする」「〜とする」の文末。
- 条文の形（第1条、項、号）、定義の条、ただし書き、長い条件の文。
- 「〜に関して」「〜を実施」のような名詞化の表現（slop-catalog.md 7章の名詞化の表現）。

## 2. それでも直すもの

- 絵文字、チャット応答の名残、本文に残ったAIへの指示、定型の結び（slop-catalog.md 6章）。
- 根拠のない誇張（飛躍的、画期的）と、意味のぼやけた流行語。正式な用語ではないので、他の種類と同じに扱う。
- 条件や例外がどの項や動作に掛かるかが読み取りにくい文。掛かる先が1つに決まるときのみ修正し、決まらなければ確認する。

## 3. 長さと省略

- 条、項、号の数と順序と番号を変えない。条文を分けたり繋いだりしない。
- 数値、期日、期間、金額と、それが掛かる範囲を変えない。
- 許可（〜してよい）、能力・権限（〜できる）、説明（〜する）、保証（必ず〜する、〜を保証する）は仕様の違いなので、互いに置き換えない。「〜場合がある」は言い切らず、説明に「必ず」「保証する」を追加しない。
- 多くは決まりの文書だが、立場は種類ではなく本文の手がかりで決める（SKILL.md「文書の立場と文末」）。
- 会話やファイルからは事実を補わない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 申請者は、住所を変更したときは、14日以内に届出を行わなければならない。 | 残す（義務の言葉、期間、「届出を行う」は規程の表現） |
| この契約の期間は、2027年4月1日から1年間とする。 | 残す（期日と期間、「〜とする」を変えない） |
| 本システムは、利用者の利便性を飛躍的に向上させる画期的な仕組みである。 | 誇張の言葉を修正する候補（slop-catalog.md 7章）。元にない効果や数値は追加しない |
